Projects

BioScope

An interactive biodiversity platform that simulates the ecological impact of species removal. Built with Next.js, TypeScript, Snowflake, and Google Gemini. Won 1st Place in UI/UX at DataHacks 2026.

Browser Eats

An AI-powered food delivery comparison application that uses parallel browser agents to compare prices across DoorDash, Uber Eats, and Grubhub. Built with Next.js, Playwright, browser automation, and Supabase.

TubeScope

An interactive data science application analyzing YouTube trending video lifespans using survival analysis and Kaplan-Meier estimators. Built with Python, pandas, and Streamlit.

PantryPal

A recipe recommendation application that uses image classification to recognize ingredients and suggest meals. Combines convolutional neural networks with the USDA FoodData Central API.

US Power Outage Analysis

An exploratory data analysis of major US power outages from 2000 to 2016, investigating outage severity, geographic patterns, population density, and underlying causes. Created using Python, pandas, and Plotly.

UCSD Lecture Attendance Analysis

A data science project exploring relationships between lecture attendance, student experiences, and academic performance at UC San Diego. Used Python, web scraping, pandas, and VADER sentiment analysis.
